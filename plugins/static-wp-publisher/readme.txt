Generate and safely refresh static HTML from public WordPress pages.

== Description ==

Static WP Publisher keeps WordPress as the editorial source while generating public static HTML. The Core provides unlimited local publication. Portable ZIP and directory exports are supplied by a separate add-on.

This is an early development release. It contains no SEO or LLM optimization module.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/static-wp-publisher`.
2. Activate it in WordPress.
3. Open Static Publisher, run the diagnostic, generate a preview, and publish only after review.
