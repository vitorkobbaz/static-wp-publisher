# WordPress.org directory assets

Files in this folder are published to the plugin's SVN `assets/` directory by the release workflow. They are not part of the plugin package.

Required before the first release:

| File | Size | Purpose |
| --- | --- | --- |
| `icon-128x128.png` | 128×128 | Plugin icon |
| `icon-256x256.png` | 256×256 | Plugin icon (high density) |
| `banner-772x250.png` | 772×250 | Plugin page banner |
| `banner-1544x500.png` | 1544×500 | Plugin page banner (high density) |
| `screenshot-1.png` | any | Dashboard (readme screenshot 1) |
| `screenshot-2.png` | any | Test visitor version (readme screenshot 2) |
| `screenshot-3.png` | any | Portable export (readme screenshot 3) |

An `icon.svg` may be used instead of the two PNG icons.
